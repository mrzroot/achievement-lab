# Practice a documentation review

Use a dedicated practice branch to fix one ambiguous sentence in a practice note. Make the correction useful and keep it separate from unrelated edits.

1. Open a draft pull request and describe the confusion, your proposed wording, and what you checked in the Markdown preview.
2. Invite a collaborator who has agreed to practise with you. Ask them to check whether the new wording answers the original question and to leave one concrete suggestion.
3. Respond to the suggestion in the thread. If appropriate, revise the wording in a new commit and request another look. Keep the conversation as a record of the decision.
4. Verify the final diff contains only the intended change. Merge only if the owner wants to retain the exercise; otherwise close the draft.

A useful review is the goal. Do not manufacture approvals, identities, contributions or achievement activity.
